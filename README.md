# SMO V2 — Smart Manufacturing Operations

Production-management system for garment manufacturing: process planning with workflow graphs, QR-based bin tracking and merging, production orders, HR and store management.

| Folder | Contents |
|---|---|
| [`backend/`](backend/) | Spring Boot 3 + MySQL REST API — see [backend/README.md](backend/README.md) |
| [`frontend/`](frontend/) | Flutter cross-platform app — see [frontend/README.md](frontend/README.md) |

## Quick start

```bash
git clone https://github.com/BendalamRajeev/SMO-V2.git
cd SMO-V2

# Backend (Java 17, MySQL 8)
cd backend && ./mvnw spring-boot:run

# Frontend (Flutter 3.8+), in a second terminal
cd frontend && flutter pub get && flutter run
```
